# Commands
Command aktif berasal dari metadata plugin yang diregistrasikan runtime. Daftar di bawah adalah command yang tersedia pada base saat dokumentasi ini dibuat.

## Main

- `.ping`
- `.status`
- `.help [command]`
- `.menu`
- `.allmenu`
- `.category`
- `.owner`

## Owner

- `.addowner <nomor>`
- `.delowner <nomor>`
- `.listowner`
- `.jadibot <nomor>`
- `.listjadibot`
- `.stopjadibot <nomor>`
- `.listgc`
- `.backup`
- `.autoread on/off/status`
- `.anticall on/off/status`
- `.antispam on/off/status/reset`
- `.muteuser @user`
- `.reload [plugin]`
- `.maintenance on/off`

## Security

- `.bancmd`
- `.bancat`
- `.botsetting`

Global ban command/category memiliki pengecualian untuk command pengelolaan ban sesuai metadata plugin.

## Group Setting

- `.groupsetting`
- `.welcome on/off`
- `.setwelcome <pesan>`
- `.goodbye on/off`
- `.setgoodbye <pesan>`
- `.antispamgrup on/off/status`
- `.antisw on/off/status`
- `.antitoxic on/off/status`
- `.mute @user`
- `.unmute @user`
- `.listmute`
- `.gbancmd`
- `.gbancat`

## Legacy Games

- `.snake`
- `.ttt`

Kedua command dipertahankan tetapi tidak lagi menjadi fokus pengembangan.
